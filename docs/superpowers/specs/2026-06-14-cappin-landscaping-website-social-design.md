# Cappin Landscaping Website + Social Brand Design Spec

Date: 2026-06-14

## Goal

Create a modern, clean, professional website for Cappin Landscaping that feels premium without losing the family-owned and operated character of the company. The site should move Cappin away from a basic service website and toward a polished design-build brand with strong local proof, project storytelling, and a distinct visual system that can carry into social media.

The website should make visitors think:

- Cappin can handle full landscape design-build projects.
- Cappin is local, trusted, family-owned, and approachable.
- Cappin has real proof from recognizable Fishers, McCordsville, Lawrence, and Indianapolis-area work.
- Cappin is organized, professional, and current.

## Brand Direction

The new brand system should be driven by the existing Cappin Landscaping logo:

- Bold, italic, athletic heading energy inspired by the "CAPPIN" logo lettering.
- A restrained script accent inspired by the "Landscaping" logo lettering, used sparingly.
- A clean professional base using black, white, charcoal, stone, deep green, warm tan, and copper/gold accents.
- Strong project photography as the main visual asset.
- Minimal decorative graphics. The photos, logo, spacing, and typography should carry the premium feel.

The tone should be confident, clear, and local:

- Premium but not corporate.
- Family-owned but not casual or homemade.
- Professional but still personal.
- Focused on real project outcomes instead of generic landscaping claims.

## Site Structure

The initial website prototype should include five primary pages or page sections:

1. Home
2. Projects
3. Services
4. About
5. Quote / Contact

The first build can be a polished static or frontend prototype. The priority is visual direction, content structure, and conversion flow. Final hosting and CMS decisions can come after the prototype is approved.

## Home Page

The home page should be the primary sales page.

Required sections:

- Header with visible Cappin logo, clear navigation, and call/text CTA.
- Hero with a large project image, direct positioning, and quote CTA.
- Short trust statement: family-owned and operated, local to the Indianapolis area.
- Featured proof section with three to five strongest projects.
- Services overview that presents the full range without overwhelming the page.
- Before/during/after or transformation section.
- About preview that connects the premium work to the family-owned story.
- Final quote CTA.

Recommended hero message:

> Landscape design, installation, and outdoor upgrades built with a family-owned standard.

Recommended support message:

> Cappin Landscaping helps homeowners, communities, and local properties turn tired beds, drainage issues, and unfinished outdoor spaces into clean, intentional landscapes.

Featured case studies:

- Emerald Springs Community Entrance Design-Build, McCordsville, IN
- Fishers Landscape Foundation + Lighting

- 2025 Pool Landscape Design-Build

Project cards should include:

- Project title
- Location when known
- Scope tags
- One-line story
- Strong image

The Projects page should support filters or categories:

- Design-build
- Planting
- Rock and mulch
- Drainage and grading
- Lighting
- Maintenance and refreshes
- Commercial / community

## Services Page

Services should show everything Cappin offers while still making design-build the premium lead.

Primary services:

- Landscape design and installation
- Full tear-outs and rebuilds
- Planting and bed installs
- Rock, mulch, edging, and bed refreshes
- Drainage, buried downspouts, and French drains
- Grading, top dressing, seeding, and straw
- Landscape lighting
- Seasonal planters and annual color
- Mowing and maintenance

Each service should include:

- Short plain-language description
- Typical project examples
- Relevant project image or proof
- Quote CTA

## About Page

The About page should reinforce trust and roots.

Content themes:

- Family-owned and operated.
- Local service area and familiarity with Fishers, McCordsville, Lawrence, and Indianapolis-area properties.
- Cappin roots and company growth.
- Angels of East Africa community/root story, if the user wants that included publicly.
- Professional standards: clean work, communication, follow-through, and thoughtful design.

The About page should avoid sounding like a generic company biography. It should feel like the story behind a serious local landscaping company.

## Social Media Brand System

The website should define a social media look that feels unmistakably Cappin.

Social templates:

- Project transformation carousel
- Before / during / after
- Problem solved
- Service spotlight
- Community project spotlight
- Lighting reveal
- Mulch refresh
- Seasonal planter
- Family-owned / roots post
- Review or trust post

Initial social relaunch content should be built around:

- Emerald Springs showcase
- Fishers design-build and lighting
- Modern building project
- Pool landscape project
- Drainage / French drain problem solved
- Mulch refresh season
- Planters and annual color
- Family-owned Cappin story

Visual rules:

- Use the same black, white, deep green, stone, warm tan, and copper/gold palette as the website.
- Use project photography full-bleed or in clean editorial crops.
- Add logo placement consistently.
- Use bold italic headings for post hooks.
- Keep captions clear, local, and project-specific.

## Implementation Approach

Build a polished local prototype first.

Recommended implementation:

- A modern frontend website in the existing workspace, isolated from unrelated business app code where practical.
- Use static project data for the first prototype.
- Use organized local image assets from `cappin-brand-assets/` and selected current-site archive assets.
- Make the first screen a real usable website experience, not marketing-only filler.
- Include responsive desktop and mobile layouts.
- Start a local dev server and review in the in-app browser.

The prototype should include:

- Home page
- Projects page or projects section
- Services page or services section
- About section
- Contact/quote section
- Branded social preview section or page showing example post directions

## Success Criteria

The first website prototype is successful when:

- The Cappin logo is visible and readable in the header.
- The site immediately feels modern, clean, premium, and professional.
- The family-owned/local feel is present without making the site feel small.
- Full landscape design-build is clearly the lead service.
- The site showcases the breadth of services without becoming cluttered.
- Emerald Springs, Fishers, modern building, pool, and other key projects are clearly represented.
- The design works on desktop and mobile.
- The visual system can extend naturally into branded social media posts.

## Open Launch Questions

These do not block the first prototype, but should be answered before final launch:

- Confirm final phone number and preferred CTA wording.
- Confirm exact service area wording.
- Decide whether Angels of East Africa should be included publicly.
- Decide whether the new site will replace Wix directly or serve first as a blueprint.

## Scope Boundaries

This spec covers the website prototype, content architecture, project storytelling, and social brand direction.

This spec does not include:

- Final production hosting setup.
- Domain transfer or Wix replacement steps.
- Full CMS implementation.
- Automated quote form backend.
- Final social post export package.

Those can be planned after the prototype direction is approved.
